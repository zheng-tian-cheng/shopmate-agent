# ShopMate 商品数据与图片许可核验清单

更新日期：2026-11-01。ShopMate 是非商业的个人学习与求职展示项目，不是真实电商平台。

商品数据和商品图片分开核验：

| 内容 | 数据文件 | 校验测试 |
| --- | --- | --- |
| 型号、价格、参数及来源 | [`data/products.json`](../data/products.json) | `frontend/tests/catalog-data.test.ts` |

## 一、商品数据

### 核验规则

| 字段 | 可接受的来源 | 查不到时 |
| --- | --- | --- |
| 品牌、型号 | 品牌官网、官方新闻稿或明确写出型号的媒体报道 | 不接入 |
| 人民币价格 | 来源里明确写出的价格，口径照抄（售价、定价、原价、建议零售价、官网标价、首发到手价等） | 记为“价格待核验”，不能声称符合预算 |
| 主动降噪、标称降噪深度、佩戴方式、续航、重量、蓝牙版本 | 品牌官网规格页或官方新闻稿；官方不可访问时可用明确的媒体报道，并标注来源类型 | 记为“未知” |
| 官方产品资料链接 | 品牌官网产品页；没有时用官方发布稿 | 为空 |

- **价格只要和来源对得上**：`priceType` 照抄来源的口径，`priceConditions` 写明来源和日期；同一来源同时给了常规价和首发优惠价时，用常规价，优惠价写进价格说明。漫步者 W800BT Free 降噪版只找到“首发到手价”，按这个口径展示。
- **数值必须能在来源中找到**：测试会检查每个价格、降噪深度、续航小时数、重量和蓝牙版本是否出现在所引用来源的 `supports` 说明里。
- **续航和重量分口径记录**：续航分“单次 / 含充电盒 / 未注明”和“降噪关 / 降噪开 / 未注明”；重量分“单耳 / 整机 / 未注明”。来源没写清的就记“未注明”，不自行换算。
- **标称降噪深度只是厂商或媒体给出的数值**，界面注明“标称值，不代表实际降噪效果”。
- 第三方导购文章、电商链接标题、竞品 AI 回答只作线索，不作依据。
- 不同来源冲突时以官方为准，并在 `notes` 记录分歧。
- 依据描述推断的字段（如根据“硅胶耳塞”记为入耳式、根据“综合续航”记为含充电盒），在 `notes` 或续航说明中写明依据。
- 同系列或同代际的不同型号分开记录，参数和价格不混用。

## 二、商品图片

### 四种状态与展示规则

| 状态 | 含义 | 公开展示 | 本地开发 |
| --- | --- | --- | --- |
| `licensed` 准确型号照片 | 开放许可，确认为该型号 | 显示，并按许可要求署名 | 显示 |
| `demo` 演示示意图 | 同类耳机的开放许可照片，按佩戴方式匹配，**不是该型号** | 显示；详情大图标注“演示示意图 · 非该型号实拍”并在“参数来源”里署名，列表、首页和推荐卡片用页面级说明 | 同左 |
| `reference-only` 仅本地参考 | 临时参考素材，**未获授权** | 不显示 | 只在 `NEXT_PUBLIC_IMAGE_MODE=local` 时显示，并标注“本地参考图 · 未授权” |
| `missing` 缺失 | 没有合适图片 | 显示规范占位图，详情页附官方产品资料链接 | 同左 |

**示意图的选用规则（2026-11-01 前端优化后）：**
- 来源只用 Wikimedia Commons 上许可明确的照片（CC BY-SA 4.0 或 CC0），许可从 Commons 的机读信息逐张核对。Unsplash 拦截自动下载，没有绕过。没有使用 AI 生成图（当前没有图片生成工具）。
- 统一为干净的棚拍构图：主体居中、柔和阴影、4:3、800×600。为让 15 款商品可辨识，在同一组棚拍原图上调整背景与机身配色（米色、浅蓝、浅绿、淡紫、浅粉、暖灰），部分镜像、裁切不同；每款商品一张，不重复。每张图的修改记录在 `product-images.json` 的 `modifications` 中，CC BY-SA 4.0 的修改版仍按 CC BY-SA 4.0 发布。
- 不再使用之前那组紫色桌布、强反光、有灰尘的实拍图。
- 按佩戴方式匹配：入耳式用带硅胶耳塞的图，半入耳式用无耳塞的图，头戴式用头戴耳机图；佩戴方式未核实的商品只用看不出佩戴方式的**闭合充电盒**图，而且来源必须提到充电盒（耳机盒、耳机舱）或真无线；都没有的不配图（Redmi Buds 6 Pro）。
- 充电盒原图正面印有原品牌的英文标语，已擦除，画面中没有可辨认的品牌标识。
- 展示方式：详情大图标注“演示示意图 · 非该型号实拍”，详情页“参数来源”里署名作者、许可和修改说明；列表、首页和推荐卡片不逐张加标签，改为页面级说明“部分商品图片为演示示意”。

**本地参考素材的使用方法**（未授权素材只用于本地界面验证）：
1. 把图片放进 `frontend/reference-images/`（文件名用小写字母、数字和连字符），这个目录已经写进 `.gitignore`，不会提交到仓库。
2. 在 `data/product-images.json` 中把对应商品的状态改为 `reference-only`，并填写 `referenceFile`。
3. 用 `NEXT_PUBLIC_IMAGE_MODE=local npm run dev` 启动。参考图只通过开发专用路由提供，生产构建和公开模式下一律返回 404。

按你的要求，不逐一向品牌申请授权。公开作品集上线前，再对素材做最终审核。
