# ShopMate｜RAG 数据采集报告 V0.1

> 2026-11-02 · 第一轮数据采集已完成；RAG 检索尚未开发。本文的数字都可以在 [`data/rag/sources_manifest.json`](../data/rag/sources_manifest.json) 中核对，括号里的编号是登记表的 `source_id`。

## 1. 数据采集概况

ShopMate 用结构化商品数据（`data/products.json`）筛选商品。为了回答降噪效果、佩戴舒适度这类参数表回答不了的问题，第一轮为全部 15 款耳机采集了原始资料，后续用于文档解析、分块和 RAG 检索。

**采集原则**

- 只用商品数据中的商品 ID、品牌和完整型号检索，不增加或替换商品。
- 每份资料都核对准确型号和地区版本。
- 不绕过 403、验证码或付费墙。检索摘要不算已核验的原文。
- 官方文件保存原文；第三方评测只登记链接、作者、日期，以及核验过的简短事实和测试条件。

**实际成果**

| 项目 | 数量 |
| --- | --- |
| 本地原始文件 | 23 份（PDF 4 份、HTML 19 份），约 14MB，全部打开核对过型号 |
| 官方说明书 | 4 份 PDF：索尼 WF-C510、WH-CH720N 两款，各有英文版和简体中文版 |

原始文件只在本地保存，不提交到公开仓库（见 `.gitignore`）。需要时，按登记表中的 URL 重新获取，并用 SHA-256 校验。哈希和链接只用于追溯，不代表这些文件获得了再分发许可。

## 3. 关键发现

1. **覆盖不均匀。**
   - 资料较完整的只有索尼 WF-C510、WH-CH720N 和华为 FreeBuds 6i，都在 499–799 元价位。
   - QCY、漫步者、惠威只有媒体报道。
   - 降噪或隔音的实测数据只有 SoundGuys 两篇（`sony-wf-c510--04`、`sony-wh-ch720n--04`），其余都是厂商标称值或主观评价。
2. **低价耳机缺少可靠的使用体验证据。**
   - 200 元以内的 4 款（Enco Air4、Redmi Buds 6、6S、FreeBuds SE 3）只有官方标称值和少量主观评测。
   - Redmi Buds 6 的两篇评测对降噪的结论相反（`redmi-buds-6--03`、`--04`）。
   - 对这个价位，RAG 短期内能给出的最诚实回答是“证据有限”。
3. **地区版本和相似型号容易混淆。**
   - 小米越南站本轮可以访问，但对应的是越南版（`redmi-buds-6--01`），不能直接认定与国行一致。
   - OPPO 和一加的资料来自海外站。
   - 漫步者 W800BT Free 有降噪版和非降噪版两个型号（`edifier-w800bt-free-anc--03`）；荣耀的支持文档是通用说明，不是 X9 专属（`honor-earbuds-x9--02`）。
   - 登记表用 `region_version` 和 `usable_as_evidence` 标出了这些情况。
4. **官方标称值不等于实测结果，不能直接比较。**
   - 荣耀、vivo、OPPO 的官方脚注都写明，降噪 dB 是自家实验室测得的“最大降噪深度”，所以不能跨品牌按 dB 排名。
   - 续航同样有差异：华为 FreeBuds 6i 官方标称开启降噪 5 小时，Notebookcheck 在开启降噪、使用 LDAC 时实测约 2.9 小时（`huawei-freebuds-6i--04`）。
5. **舒适度没有统一的比较标准。** 评测者的佩戴体验因人而异，回答时必须说明个体差异，不能写成适用于所有人的结论。

**对初步调研的更正**

- OPPO Enco Air4 的官方产品页写明了“主动降噪最高 32dB（实验室标称）”（`oppo-enco-air4--02`），初步调研遗漏了这一条。
- 初步调研时无法访问的小米越南站，本轮已经取得，但对应越南版。
- 初步调研中的商品逐款记录已经被本报告和登记表取代。

## 4. 后续工作

1. **已完成**：第一轮数据采集和来源登记。原始资料留在本地，登记表随仓库公开。
2. **下一步**：解析官方 PDF 和网页正文，按商品 ID 和主题分块，每个分块都可以追溯到登记表里的一条来源。
3. **之后**：开发向量化、检索和 Agent 集成。RAG 只用于解释、追问和比较，不改变商品筛选和排序规则。
4. **评测**：用现有评测集衡量证据检索、事实准确性和推荐解释的效果。候选评测问题见 [RAG 专项评测设计稿](ShopMate_RAG_Eval_V0.1.md)，待人工审核。
5. **人工补充**：在浏览器里读取 RTINGS 两份评测、核对小米国行官网，并为 200 元以内的商品寻找可信的中文评测。
